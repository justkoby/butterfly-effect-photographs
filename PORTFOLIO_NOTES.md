# Portfolio arrangement update

The previous collection labels often did not match the actual photographs. After a visual review of available assets, the overview now has six collections in this order:

1. Portraits
2. Birthdays
3. Couples & Families
4. Weddings
5. Beauty & Fashion
6. Headshots & Branding

The large animated portfolio hero, duplicate package cards and extended booking instructions were replaced with a compact introduction, a consistent collection grid and a short planning CTA. Individual galleries share one layout, use original image proportions and have accurate descriptive alternative text. Image dimensions reserve space while loading. Wedding images now come from the shared collection data; logo graphics and unrelated portraits were removed from that gallery.

No photo assets were deleted. Categories without matching evidence (maternity, event reportage and product photography) are not presented as curated galleries in this revision. This is a portfolio presentation change, not a change to the services offered. Those collections can return when suitable images are supplied. Older product/commercial and outdoor/lifestyle URLs redirect to relevant portrait collections; unrecognised categories return to the portfolio overview.

The homepage Selected Work animation is unchanged. The overview and collection pages are revised. The pricing CTA now correctly navigates and scrolls to the homepage packages section.

Validation: production build; desktop and 390px browser checks; every collection image decoded successfully; original aspect ratios checked; wedding content, legacy redirect and pricing anchor checked. The existing lint warnings in Navbar and StudioRental remain.
